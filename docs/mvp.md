# LinkSpace MVP

## О проекте

**Суть.** LinkSpace — это сервис для сохранения и организации полезных ссылок.
Ссылки собираются в одном месте, распределяются по коллекциям, получают теги и
отметку «избранное», а потом быстро находятся через поиск и фильтры.

**Для кого.** Для тех, кто регулярно сохраняет статьи, документацию, инструменты
и учебные материалы и хочет держать их в структурированной библиотеке вместо
десятков открытых вкладок и неразобранных закладок браузера.

**Проблема.** Ссылку легко сохранить, но зачастую потом ооочень сложно найти.

## Основной сценарий

Пользователь сохраняет ссылку, добавляет ее в коллекцию, при необходимости
указывает теги или отмечает как избранную, а позже находит через поиск,
коллекцию или фильтры.

## Возможности MVP

В MVP входят:

- ссылки;
- коллекции;
- теги;
- избранное;
- поиск;
- комбинируемые фильтры;
- статистика библиотеки.

## За пределами MVP

В текущую версию не входят:

- авторизация и несколько пользователей — сервис рассчитан на одного человека;
- автоматическое получение названия, описания и изображения сайта — пользователь
  вводит их сам;
- редактирование URL — другой адрес считается новой ссылкой;
- корзина — удаление окончательное;
- пагинация — ссылки загружаются одним списком;
- база данных — данные хранятся в JSON-файлах.

## Продуктовые правила

- Каждая ссылка принадлежит одной коллекции.
- У ссылки может быть несколько тегов.
- Избранное — свойство ссылки, а не отдельная сущность.
- Один URL нельзя сохранить в библиотеку дважды.
- Названия коллекций не должны повторяться.
- Ссылку можно перенести из одной коллекции в другую.
- Непустую коллекцию нельзя удалить, пока ее ссылки не перенесены в другую.
- Поиск, коллекция, тег и избранное могут использоваться одновременно.
- URL существующей ссылки не редактируется.

## Интерфейс

LinkSpace — одностраничное приложение. Коллекции, избранное, теги и поиск меняют
текущую подборку ссылок без перехода между отдельными страницами.
