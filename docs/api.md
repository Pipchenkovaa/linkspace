# LinkSpace API

Backend LinkSpace реализован на FastAPI и предоставляет REST API для работы с
коллекциями и ссылками.

Локальный адрес:

`http://127.0.0.1:8000`

Интерактивная документация:

`http://127.0.0.1:8000/docs`

## System

| Метод | Маршрут    | Назначение                 |
| ----- | ---------- | -------------------------- |
| GET   | `/health`  | Проверить состояние API    |
| GET   | `/version` | Получить версию приложения |

`GET /health` используется frontend для проверки доступности backend.

## Collections

| Метод  | Маршрут                          | Назначение                           |
| ------ | -------------------------------- | ------------------------------------ |
| GET    | `/collections`                   | Получить все коллекции               |
| POST   | `/collections`                   | Создать коллекцию                    |
| GET    | `/collections/{id}`              | Получить коллекцию                   |
| PATCH  | `/collections/{id}`              | Переименовать коллекцию              |
| DELETE | `/collections/{id}`              | Удалить пустую коллекцию             |
| DELETE | `/collections/{id}?move_to={id}` | Перенести ссылки и удалить коллекцию |

Названия коллекций уникальны без учета регистра.

Непустую коллекцию нельзя удалить без указания другой коллекции для переноса
ссылок.

## Links

| Метод  | Маршрут       | Назначение           |
| ------ | ------------- | -------------------- |
| GET    | `/links`      | Получить ссылки      |
| POST   | `/links`      | Добавить ссылку      |
| GET    | `/links/{id}` | Получить одну ссылку |
| PATCH  | `/links/{id}` | Изменить ссылку      |
| DELETE | `/links/{id}` | Удалить ссылку       |

При создании ссылки URL нормализуется и проверяется на дубликаты.

URL существующей ссылки не редактируется.

Через `PATCH /links/{id}` можно изменить название, описание, коллекцию, теги и
статус избранного.

Например, добавить ссылку в избранное:

```json
{
	"favorite": true
}
```
