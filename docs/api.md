# LinkSpace API

Backend LinkSpace реализован на FastAPI и предоставляет REST API для работы с
коллекциями и ссылками.

Локальный адрес:

`http://127.0.0.1:8000`

Интерактивная документация:

`http://127.0.0.1:8000/docs`

## System

| Метод | Маршрут    | Назначение                 |
| ----- | ---------- | -------------------------- |
| GET   | `/health`  | Проверить состояние API    |
| GET   | `/version` | Получить версию приложения |

`GET /health` используется frontend для проверки доступности backend.

## Collections

| Метод  | Маршрут                          | Назначение                           |
| ------ | -------------------------------- | ------------------------------------ |
| GET    | `/collections`                   | Получить все коллекции               |
| POST   | `/collections`                   | Создать коллекцию                    |
| GET    | `/collections/{id}`              | Получить коллекцию                   |
| PATCH  | `/collections/{id}`              | Переименовать коллекцию              |
| DELETE | `/collections/{id}`              | Удалить пустую коллекцию             |
| DELETE | `/collections/{id}?move_to={id}` | Перенести ссылки и удалить коллекцию |

Названия коллекций уникальны без учета регистра.

Непустую коллекцию нельзя удалить без указания другой коллекции для переноса
ссылок.

## Links

| Метод  | Маршрут       | Назначение           |
| ------ | ------------- | -------------------- |
| GET    | `/links`      | Получить ссылки      |
| POST   | `/links`      | Добавить ссылку      |
| GET    | `/links/{id}` | Получить одну ссылку |
| PATCH  | `/links/{id}` | Изменить ссылку      |
| DELETE | `/links/{id}` | Удалить ссылку       |

При создании ссылки URL нормализуется и проверяется на дубликаты.

URL существующей ссылки не редактируется.

Через `PATCH /links/{id}` можно изменить название, описание, коллекцию, теги и
статус избранного.

Например, добавить ссылку в избранное:

```json
{
  "favorite": true
}
```

Перенести в другую коллекцию:

```json
{
  "collection_id": 3
}
```

## Поиск и фильтрация

`GET /links` поддерживает параметры:

| Параметр | Назначение |
| --- | --- |
| `search` | Поиск ссылок |
| `tag` | Фильтр по тегу |
| `collection_id` | Фильтр по коллекции |
| `favorite` | Только избранные ссылки |

Примеры:

```text
GET /links?search=react
GET /links?tag=frontend
GET /links?collection_id=2
GET /links?favorite=true
```

Фильтры можно комбинировать:

```text
GET /links?search=react&tag=frontend&collection_id=2&favorite=true
```

## Коды ответов

API использует стандартные HTTP-коды.

| Код | Значение |
| --- | --- |
| `200 OK` | Запрос выполнен |
| `201 Created` | Ресурс создан |
| `400 Bad Request` | Операция некорректна |
| `404 Not Found` | Ссылка или коллекция не найдена |
| `409 Conflict` | Конфликт данных |
| `422 Unprocessable Entity` | Данные не прошли валидацию |
| `500 Internal Server Error` | Неожиданная ошибка сервера |

### 409 Conflict

Используется, в частности, когда:

- URL уже существует в библиотеке;
- коллекция с таким названием уже существует;
- операция удаления коллекции конфликтует с ее текущим состоянием.

Frontend использует информацию об ошибке для выбора соответствующего
пользовательского сценария.

## Основные сценарии frontend → API

### Добавление ссылки

```text
POST /links
```

Backend:

1. проверяет данные;
2. нормализует URL, домен и теги;
3. проверяет URL на дубликат;
4. проверяет существование коллекции;
5. сохраняет ссылку.

При дубликате возвращается `409 Conflict`.

### Редактирование ссылки

```text
PATCH /links/{id}
```

Используется для изменения данных ссылки, избранного и переноса между
коллекциями.

### Удаление коллекции

Пустая коллекция:

```text
DELETE /collections/{id}
```

Коллекция со ссылками:

```text
DELETE /collections/{id}?move_to={target_id}
```

Во втором случае ссылки сначала переносятся в выбранную коллекцию, после чего
исходная коллекция удаляется.

### Проверка состояния API

```text
GET /health
```

Frontend выполняет health check раз в 30 секунд и использует результат для
отображения состояния backend.
