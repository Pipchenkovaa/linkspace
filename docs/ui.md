# LinkSpace UI

## Общая структура

LinkSpace — это одностраничное приложение.

Коллекции, избранное, поиск и теги не открывают отдельные страницы, а меняют
текущую подборку ссылок на главном экране.

Основные элементы интерфейса:

- шапка с поиском, статусом API и добавлением ссылки;
- полка коллекций;
- переключатель «Все / Избранное»;
- фильтрация по тегам;
- список карточек ссылок;
- формы и диалоговые окна.

## Библиотека

Главный экран показывает все сохраненные ссылки.

В шапке находятся:

- логотип;
- индикатор состояния API;
- поиск;
- кнопка «Добавить ссылку».

Клавиша `/` переводит курсор в поле поиска.

В заголовке библиотеки отображается общая статистика, например: «15 ссылок в 6
коллекциях».

### Полка коллекций

Каждая коллекция отображается как папка.

Папка показывает:

- название коллекции;
- количество ссылок;
- буквы доменов трех последних ссылок;
- названия двух последних ссылок.

В конце списка находится кнопка «+ Новая коллекция».

Если коллекции не помещаются по ширине, полка прокручивается стрелками или
свайпом.

### Фильтры

Над списком ссылок находятся:

- переключатель «Все / Избранное»;
- теги текущей подборки;
- информация о количестве найденных ссылок;
- кнопка сброса активных фильтров.

Показываются первые 8 тегов, остальные доступны через «Еще N».

Поиск, коллекция, тег и избранное могут работать одновременно.

Если фильтры не используются, отображается общее количество ссылок. При активных
фильтрах — «Найдено N из M» и кнопка «Сбросить».

Если в текущей подборке нет ссылок, панель тегов скрывается.

## Карточка ссылки

Карточка показывает:

- плитку с буквой домена в цвете коллекции;
- название;
- адрес без `https://`;
- описание, если оно задано;
- теги;
- название коллекции.

Название открывает сохраненную ссылку в новой вкладке.

Клик по тегу включает фильтрацию по нему.

Доступные действия:

- добавить ссылку в избранное или убрать из него;
- изменить данные ссылки;
- удалить ссылку.

На desktop кнопки редактирования и удаления появляются при наведении. На
мобильных устройствах они видны постоянно.

Удаление подтверждается непосредственно в карточке.

## Избранное

Избранное — не отдельный экран.

Переключатель «Все / Избранное» меняет текущую подборку ссылок и может
использоваться одновременно с коллекцией, тегом и поиском.

## Коллекция

Клик по папке открывает коллекцию.

При открытой коллекции:

- активная папка визуально выделяется;
- в заголовке отображаются название коллекции и количество ссылок;
- появляется «< Моя библиотека» для возврата ко всем ссылкам;
- поиск, теги и избранное работают только внутри выбранной коллекции;
- при добавлении ссылки текущая коллекция уже выбрана в форме.

### Создание коллекции

Кнопка «+ Новая коллекция» добавляет в конец полки новую папку с полем для
названия.

### Действия с коллекцией

Меню `⋯` содержит:

**Переименовать**

Название папки заменяется полем ввода.

- Enter — сохранить;
- Esc — отменить;
- клик вне поля — отменить.

**Удалить**

Открывается окно удаления коллекции.

## Добавление и редактирование ссылки

Форма используется и для создания, и для изменения ссылки.

| Поле      | Обязательное | При редактировании |
| --------- | ------------ | ------------------ |
| URL       | да           | не меняется        |
| Название  | да           | можно изменить     |
| Описание  | нет          | можно изменить     |
| Коллекция | да           | можно изменить     |
| Теги      | нет          | можно изменить     |
| Избранное | нет          | можно изменить     |

### Коллекция

Новую коллекцию можно создать прямо из формы через «+ Новая коллекция».

Если коллекций нет, поле для создания новой коллекции открыто сразу.

Если коллекция одна, она выбирается автоматически.

Коллекция, введенная внутри формы, создается только вместе с сохранением ссылки.
Если пользователь закрывает форму без сохранения, новая коллекция не создается.

### Теги

Теги добавляются по Enter или запятой.

### Валидация

Ошибки проверки данных отображаются рядом с соответствующими полями.

При попытке сохранить URL, который уже существует в библиотеке, показывается
окно дубликата.

## Удаление коллекции

### Пустая коллекция

Пользователь получает подтверждение:

> Удалить коллекцию «Development»? Это действие нельзя отменить.

Доступны действия «Отмена» и «Удалить».

### Коллекция со ссылками

Если в коллекции есть ссылки, перед удалением нужно выбрать другую коллекцию,
куда они будут перенесены.

Например:

> Удалить «Development»? В коллекции 8 ссылок. Выбери, куда их перенести перед
> удалением.

Кнопка «Перенести и удалить» недоступна, пока коллекция назначения не выбрана.

Если других коллекций нет, показывается подсказка:

> Других коллекций нет. Сначала создай еще одну, чтобы было куда перенести
> ссылки.

После успешного удаления, если пользователь находился внутри удаленной
коллекции, открывается коллекция, в которую были перенесены ссылки.

## Дубликат ссылки

Если пользователь пытается добавить URL, который уже существует в библиотеке,
открывается окно «Опа, такая ссылка уже есть».

### Ссылка уже в выбранной коллекции

Показывается сообщение:

> Эта ссылка уже сохранена в коллекции «Development».

Доступны действия:

- «Закрыть»;
- «Показать ссылку».

«Показать ссылку» открывает нужную коллекцию и выделяет существующую карточку.

### Ссылка находится в другой коллекции

Показывается сообщение:

> Эта ссылка уже сохранена в коллекции «University». Можно оставить ее там или
> перенести в «Development».

Доступны действия:

- «Оставить там»;
- «Перенести в Development».

При переносе существующая ссылка меняет коллекцию. Данные новой формы не
сохраняются.

## Ошибки интерфейса

### Ошибка операции

Ошибки, связанные с конкретным действием, показываются в том месте, где
пользователь выполняет это действие: в форме, карточке или диалоговом окне.

Например:

- повторяющееся название коллекции — «Такая коллекция уже есть»;
- ошибка валидации — подсказка рядом с полем;
- ссылка или коллекция уже удалена — сообщение в открытой форме или окне;
- неожиданная ошибка — «Что-то пошло не так. Не удалось выполнить действие.
  Попробуй еще раз.».

### API недоступен

Frontend проверяет `GET /health` раз в 30 секунд.

Если API не отвечает:

- в шапке меняется статус сервера;
- отображается сообщение «Эх, сервер не отвечает...»;
- показывается подсказка по запуску backend;
- доступна кнопка «Повторить»;
- кнопка «Добавить ссылку» недоступна.

Когда `/health` снова начинает отвечать, библиотека загружается автоматически.

### Ошибка интерфейса

При необработанной ошибке frontend показывает страницу:

> Что-то сломалось.

Пользователю доступна кнопка «Попробовать еще раз».
