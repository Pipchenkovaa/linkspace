# LinkSpace: фронтенд

Интерфейс библиотеки на Next.js. Запуск вместе с бэкендом описан в
[README в корне репозитория](../README.md#фронтенд).

## Установка и запуск

```bash
npm install
cp .env.example .env.local
npm run dev
```

- `app/` — страница, корневой layout, страницы 404 и ошибки, иконка;
- `components/` — шапка, полка коллекций, фильтры, карточки, формы и окна;
- `lib/api.ts` — запросы к API и разбор ошибок;
- `lib/useLibrary.ts` — состояние библиотеки: загрузка, фильтры, действия;
